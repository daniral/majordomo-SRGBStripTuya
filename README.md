💡 LED-лента Tuya для MajorDoMo
Умное RGB-устройство с авто-режимами, сценами и расширенными настройками
<p align="left"> <img src="https://img.shields.io/badge/MajorDoMo-Device-blue?style=for-the-badge"> <img src="https://img.shields.io/badge/Tuya-Cloud%20Hub-orange?style=for-the-badge"> <img src="https://img.shields.io/badge/RGB-LED_strip-ff00ff?style=for-the-badge"> <img src="https://img.shields.io/badge/PHP-7+-777bb3?style=for-the-badge"> </p>

Модуль добавляет поддержку умной RGB-ленты Tuya, работающей через официальный Tuya-хаб.

⚠️ Важно: Лента должна быть подключена через Tuya Hub.
❌ Не работает через zigbee2mqtt!

Расширяет встроенный класс SControllers, добавляя новый — SRGBStripTuya2.

Поддерживает:
✔ авто режимы по датчику/солнцу/времени
✔ дневные/ночные профили
✔ управление цветом, яркостью и сценами
✔ автотаймеры
✔ сохранение последних параметров

⚙️ Привязка свойств
Свойство Tuya	Свойство MajorDoMo	Описание
switch_led	status	Включение / выключение
work_mode	work_mode	Режим работы (цвет / сцена)
colour_data	colour_data	Цвет RGB в HEX
scene_data	workScene	Активная сцена

После привязки свойств несколько раз измените настройки из приложения Tuya,
чтобы MajorDoMo получил корректные данные от устройства.

🔆 Обычный режим
Включение
callMethod('ИмяОбъекта.turnOn');


Если параметры не указаны — используются сохранённые или дефолтные:

Параметр	Значение по умолчанию
colorSaved	#ffff00
levelSaved	100
sceneNameSaved	«Синее небо»
mode	1 (цвет)
Включение с параметрами
callMethod('ИмяОбъекта.turnOn', [
    'level'     => '1..100',
    'color'     => '#RRGGBB' / '#RGB' / пресет,
    'sceneName' => 'Название сцены',
    'mode'      => '1|2'
]);


Пример:

callMethod('Лента.turnOn', [
    'level' => 50,
    'color' => '#FFFF00',
    'sceneName' => 'Лес',
    'mode' => 1
]);


При включении вручную выставляется flag = 1
— авто-режим временно отключается.
Чтобы вернуть авто-режим — вызовите turnOff.

🤖 Авто режим

Включение авто-режима:

callMethod('ИмяОбъекта.turnOn', ['autoMode' => 1]);


Используется, например, с датчиком движения.

Как работает:

работает указанное время timerOff (сек)

если timerOff = 0 — не выключится автоматически

если presence = 1 — не выключается

когда presence меняется на 0 → запускается таймер выключения

поддерживает дневные / ночные параметры

режим работы:

1 — День

2 — Ночь

3 — Круглосуточно

📅 Режимы автоматизации
1️⃣ По времени (workingBy = 1)

после времени ночного периода → ночные параметры

после времени дневного периода → дневные параметры

2️⃣ По солнцу (workingBy = 2)

после заката → ночные

после восхода → дневные

Нужно заполнить свойства:

sunriseTime

sunsetTime

Можно добавлять/отнимать время:

addTimeSunrise + signSunrise

addTimeSunset + signSunset

3️⃣ По датчику освещения (workingBy = 3)

работает только ночью

включение по условию:

illuminance < illuminanceMax


⚠️ Датчик освещения не протестирован в реальной установке.

🕹 Запуск авто-режима с параметрами
callMethod('ИмяОбъекта.turnOn', [

    'color' => '#RRGGBB' / '#RGB' / пресет,

🎨 Сцены
🧾 scenesList

Хранит список всех сцен в формате:

Название=Значение,Название=Значение,...


Если свойство пустое — автоматически заполняется дефолтными.

Пример:

Спокойной ночи=000e0d00002e03e802cc00000000,
Чтение=010e0d000084000003e800000000,
Осенняя прохлада=0b000000000f019003e800000000

🏷 sceneName

Хранит имя текущей сцены

Если имя найдено — подставляется нужный Tuya-код

Если имя отсутствует — остаётся предыдущая сохранённая

Если записано "unknown" — отображается «Неизвестная сцена»

# 💡 Led лента (Tuya)
### Простое устройство для MajorDoMo  

Модуль добавляет поддержку умной Led ленты от Tuya. 

**Лента должна быть подключена через хаб Tuya!**  
**Не через zigbee2mqtt!**  
---  
Расширяет встроенный класс `SControllers`, добавляя новый класс **`SRGBStripTuya2`**.  

---  

## ⚙️ Привязка свойств

| Свойство Tuya  | Свойство в MajorDoMo | Описание                                    |
|----------------|----------------------|-------------------------------------------- |
| `switch_led`   | `status`             | Включение / выключение лампы                |
| `work_mode`    | `work_mode`          | Режим работы (белый, цветной, сцена и т.п.) |
| `colour_data`  | `colorWork`        | Цвет RGB в HEX                              |
| `scene_data`   | `sceneWork`          | Активная сцена                              |

`После привязки свойств надо поизменять свойства из приложения чтобы прилетели данные в объект`.
---

## 🔧 Методы управления

| Метод       | Назначение            | Пример вызова                                                  |
|-------------|-----------------------|----------------------------------------------------------------|
| `turnOn`    | Включить лампу        | `callMethod('Имя Объекта.turnOn');`                            |
| `turnOff`   | Выключить лампу       | `callMethod('Имя Объекта.turnOff');`                           |
| `switch`    | Переключить состояние | `callMethod('Имя Объекта.switch');`                            |
| `levelDown` | Уменьшить яркость     | `callMethod('Имя Объекта.levelDown', array("value"=>1--100));` |
| `levelUp`   | Увеличить яркость     | `callMethod('Имя Объекта.levelUp', array("value"=>1--100));`   |
| `setLevel`  | Установить яркость    | `callMethod('Имя Объекта.setLevel', array("value"=>1--100));`  |
| `setColor`  | Установить цвет       | `callMethod('Имя Объекта.setColor', array("value"=>#RRGGBB));` |

---

## 🎨 Работа со сценами

### 🧾 `scenesList`

Хранит список доступных сцен в формате:

Название=Значение,Название=Значение,...

**Пример:**
Спокойная=000e0d0000000000000000c80000,Чтение=010e0d0000000000000003e801f4,Работа=020e0d0000000000000003e803e8

- Если свойство `scenesList` пустое — оно автоматически заполнится дефолтными сценами.  
- Можно редактировать список вручную, добавлять свои сцены или полностью заменить его.  

---

### 🏷 `sceneName`

Хранит **имя текущей активной сцены**.

- Можно установить сцену по имени (Majordomo автоматически подставит нужный код).  
- Если указанное имя отсутствует в списке — установится **последняя сохранённая сцена**.  
- Если в `sceneName` записано `"unknown"` — в интерфейсе отображается **«Неизвестная сцена»**, но список сцен остаётся доступен для выбора.
